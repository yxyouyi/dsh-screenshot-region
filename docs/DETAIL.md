# dsh-screenshot-region

在 DeepSeek Harness 的输入框旁加一个截图入口：点一下、拖一个框、松手，框内图片直接进入对话框草稿。

## 一次拖拽，不是两步

多数截图插件是「先截整屏 → 再在页面里框选」。本版把框选交给 Windows 原生覆盖层：

1. 点输入框左下的截图按钮
2. 屏幕定格，左上角提示「拖动鼠标框选要截取的范围 · 松开鼠标完成 · Esc 或右键取消」
3. 按住左键拖一个框，松手即完成
4. 框内图片作为草稿附件进入输入框，可以继续打字再发送

`Esc` 或右键取消；拖动不足 8px 不生效，误点不会截整屏。

## 窗口显隐

按钮右侧的 `▾` 选择截图时是否隐藏 Harness 窗口：

- **保留本窗口**（默认）：定格画面与屏幕上看到的一致，框选所见即所得
- **隐藏本窗口**：先隐藏再截图，成品里没有自己；选择会被记住

## 依赖与限制

- Windows 10/11，Windows PowerShell 5.1 或 PowerShell 7
- DSH `>= 0.2.0-rc.1`
- 多显示器按整个虚拟桌面截取，坐标与真实屏幕像素一致

## 相对上游

本包是 `dsh-plugin-screenshot@0.3.5`（MIT）的整理版，除新增原生框选层外，还修复了：页面浮层被输入框裁剪、单击误选整窗、`Form.DoubleBuffered` 受保护属性赋值报错、脚本缺少 UTF-8 BOM 导致解析失败、宿主可选依赖解析失败时整条 entry 不加载。
